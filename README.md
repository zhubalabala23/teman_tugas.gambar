🎨 Daftar Harga – temantugas.gambar_

Halaman price list (card harga) untuk akun Instagram temantugas.gambar_ – Jasa Gambar Sketsa & Wajah. Dibuat sebagai web frontend statis, tanpa backend, dengan tema warna yang diambil dari logo (krem & merah marun).

✨ Fitur
Card harga dengan tiga kategori yang bisa diganti lewat tab:
Sketsa Wajah – Wajah Simple, Wajah Realistis, Couple / Keluarga
Sketsa Objek – Bunga & Objek, Pemandangan, Arsitektur & Perspektif
Joki Gambar Tugas – Tugas Dasar, Tugas Seni Rupa, Paket 5 Lembar
Mendukung harga pasti dan kisaran harga (contoh: Rp 50.000 – Rp 75.000).
Badge ⭐ Paling Laris pada card pilihan.
Tombol Pesan via WhatsApp yang membuka chat dengan pesan otomatis (nama paket, kategori, dan harga).
Info pengiriman (Gojek, Gosend, Tiki, Lion Parcel, Reguler) dan metode pembayaran (Dana, Gopay, BCA).
Responsif untuk HP dan desktop, serta otomatis mengikuti mode terang / gelap perangkat.

HTML
CSS
JavaScript (vanilla)
Tailwind CSS (via CDN, versi 3.4.17)
